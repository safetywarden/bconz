# DRA v0.2

Drug Repurposing Agent converts RDIA disease intelligence into falsifiable drug x disease x responder hypotheses.

Output: Drug X + Disease Y + genotype/phenotype Z + biomarker B + regimen concept C -> evidence for/against -> India validation -> kill criterion -> differentiation/IP hypothesis.

Decisions: ADVANCE, INVESTIGATE, KILL, BENCHMARK. Patent/IP fields are preliminary research signals only and require professional review.
